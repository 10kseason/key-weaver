# Samples

Minimal osu!mania files for converter smoke tests.

- `simple_4k.osu`: 4K taps, a chord, and one hold note.
- `simple_7k_ln.osu`: 7K hold-heavy sample for compression and LN conflict checks.
- `simple_bms_4k.bms`: minimal 4K BMS sample for BMS parser/exporter smoke checks.

These files use synthetic chart data only.
